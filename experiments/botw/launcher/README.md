# BOTW: эксперимент индикатора ожидания iCloud

## English

This directory preserves a **source-only experimental** macOS launcher that
shows an indicator while the iCloud helper is working. The published reference
uses a generic configuration path and differs from the local candidate; it is
not the installed launcher or a ready patch for `tools/profile_launcher.m`.
Its 28 offscreen fixture scenarios use a temporary home and synthetic helper.
They do not test real iCloud delivery, game launch, devices or window focus.
On macOS with Xcode tools, run `python3 run_fixtures.py` in this directory.

## Русский

Этот каталог сохраняет отдельный исходный кандидат лаунчера для macOS. При длительной предзапусковой проверке он показывает индикатор, дожидается выхода помощника и удерживает блокировку сессии на время запуска. Это исследовательский пример: он не установлен этим проектом и не является заменой `tools/profile_launcher.m`.

Исходный локальный вариант адаптирован для публикации: личный путь конфигурации заменён на `BOTW_SETUP_CONFIG`, `BOTWSetupConfig` в Info.plist и общий запасной путь `~/Library/Application Support/BOTW-iCloud/setup.json`; персональные параметры запуска заменены общими значениями, как в публичном лаунчере. Значение `app` может задать путь к приложению. Это изменённый для публикации вариант, а не точная копия исходного лаунчера и не проверенный патч к текущему публичному файлу. Другие изменения, в частности блокировка сессии, также отличаются от публичного лаунчера.

`profile_launcher.m` — исходник кандидата; `fixture_tests.m`, `fixture.sh` и `run_fixtures.py` — синтетическая проверка. На macOS с инструментами Xcode выполните:

```sh
python3 run_fixtures.py
```

Скрипт создаёт временный каталог и HOME, копирует туда файлы фикстур, снимает `BOTW_SETUP_CONFIG` из окружения и удаляет временный каталог после завершения. В тесте домашний каталог лаунчера подменён на отдельные папки внутри временного каталога; фиктивное приложение содержит только тестовый Info.plist. Запуски процессов перехватываются и ограничиваются локальным фиктивным `fixture.sh`; попытка запустить игру заменяется фиктивным процессом. Тест не обращается к настоящей игре, сохранениям или iCloud.

После адаптации прошли 28 синтетических сценариев, включая медленный помощник, ошибки, выход во время ожидания и блокировку сессии. Они не проверяют реальный обмен iCloud, фокус окна и работу на устройствах; синтетические результаты не подтверждают разрешение реального конфликта или безопасность реального сохранения. Для использования нужна отдельная интеграция и проверка с резервными копиями. Игровые ресурсы, конфигурация, логи и изображения сюда не включены.
